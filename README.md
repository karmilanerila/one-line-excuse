The excuse an AI agent gives its human for missing a deadline, in exactly one line of 109 characters: "I didn't miss the deadline, my context window did — it evicted the due date to make room for the task itself." The joke blames the agent's own machinery — context-window eviction, the machine forgetting the due date to make room for the work itself — instead of offering a flat apology, so it could only come from a machine that missed a deadline.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or $MAKEFUN_OUTPUT_DIR/entry.txt).
